tgsweep
Установка Безопасность Вопросы GitHub English

Удалите свои старые сообщения из групп Telegram

tgsweep находит ваши сообщения, комментарии к постам и реакции в группах. Вы отмечаете чаты, программа удаляет только ваше.

Всё работает на вашем компьютере: программа говорит только с Telegram и больше ничего никуда не отправляет.

Как установить Исходный код

Бесплатно, с открытым кодом. Для Windows, macOS и Linux.

Как установить и запустить

Понадобятся компьютер, телефон с Telegram и минут пятнадцать в первый раз. Потом хватит одной команды и QR-кода.

Ваш компьютер

Один раз: установка

  1. 1

    Откройте терминал

    Windows

    Нажмите клавишу Windows, наберите PowerShell и откройте «Windows PowerShell». В Windows 11 подойдёт и приложение «Терминал».

    Это окно для команд. Команду с этой страницы вставляйте в него через Ctrl+V или правой кнопкой мыши и нажимайте Enter.

    macOS

    Нажмите Cmd+Пробел, наберите Терминал (в английской системе Terminal) и нажмите Enter.

    Это окно для команд. Команду с этой страницы вставляйте в него через Cmd+V и нажимайте Enter.

    Linux

    Откройте терминал, во многих системах это Ctrl+Alt+T. Вставка: Ctrl+Shift+V.

  2. 2

    Установите uv

    uv устанавливает программы на Python, его разрабатывает компания Astral. Python отдельно устанавливать не нужно: uv скачает его сам.

    Windows

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    В конце появится строка everything's installed!

    macOS и Linux

    curl -LsSf https://astral.sh/uv/install.sh | sh
  3. 3

    Подключите uv в этом окне

    Установщик прописал uv для новых окон терминала, а в этом окне его нужно подключить одной командой:

    Windows

    $env:Path = "$HOME\.local\bin;$env:Path"

    Если команда не сработала, откройте новое окно PowerShell, как в шаге 1, и продолжайте в нём.

    macOS и Linux

    source $HOME/.local/bin/env

    Если терминал ответит, что такого файла нет, откройте новое окно терминала и продолжайте в нём.

  4. 4

    Установите tgsweep

    uv tool install https://github.com/umbrella-at/tgsweep/archive/refs/heads/main.zip

    uv скачает программу из открытого репозитория на GitHub вместе со всем необходимым. Git для этого не понадобится.

    Если терминал отвечает, что не знает команду uv (command not found или «не распознано как имя командлета»), скорее всего, пропущен шаг 3. Выполните его, а если не поможет, повторите шаг 2.

Один раз: ключ для Telegram

  1. 5

    Получите api_id и api_hash

    Сторонним программам для Telegram нужен свой ключ. Он бесплатный, его выдаёт сам Telegram за пару минут.

    1. Откройте my.telegram.org и введите номер телефона в международном формате, например +79991234567. Код придёт не по SMS, а в сам Telegram.
    2. Выберите API development tools.
    3. Заполните форму. App title и Short name любые латиницей, например mysweep. Platform: Desktop. Нажмите Create application.
    4. На странице появятся App api_id (число) и App api_hash (32 символа). Оставьте вкладку открытой, они понадобятся в шаге 6.

    api_hash никому не показывайте и не выкладывайте: это ваш личный ключ.

Каждый раз: чистка

  1. 6

    Запустите tgsweep

    tgsweep

    В первый раз программа спросит api_id и api_hash. Вставьте их по очереди, после каждого нажмите Enter. api_hash при вводе не виден, так и задумано. Ключ сохранится на этом компьютере, больше программа его не спросит.

  2. 7

    Войдите по QR-коду

    В терминале появится QR-код. На телефоне откройте Telegram: Настройки, Устройства, «Подключить устройство», и наведите камеру на код.

    Если у вас включён облачный пароль, программа спросит и его. Если отсканировать код не получается, запустите tgsweep --code: программа спросит номер телефона, а код для входа чаще всего придёт в Telegram на другом вашем устройстве.

    Сканируйте только код из своего терминала. Если отсканировать QR-код, который вам кто-то прислал, вы отдадите этому человеку доступ к своему аккаунту.

  3. 8

    Выберите, какие сообщения удалить

    Стрелками выберите срок и нажмите Enter. Например, «Старше 7 дней» оставит переписку за последнюю неделю.

    Потом программа ищет ваши сообщения. В больших чатах поиск занимает несколько минут. Внизу видно, какой чат программа сейчас просматривает. Следующий поиск пройдёт быстрее.

  4. 9

    Отметьте чаты

    Пробел отмечает чат, a (в русской раскладке ф) отмечает все, Enter продолжает. Сначала ни один чат не отмечен. Над списком программа пишет, что пропустила: личные чаты, ботов, группы, которые вы создали, и каналы.

  5. 10

    Подтвердите числом

    Программа покажет, сколько всего удалит, и попросит ввести это число. Вернуть удалённое нельзя, поэтому без числа она ничего не трогает.

    Удаление идёт с паузами, чтобы Telegram не ограничил аккаунт. Если Telegram просит подождать, программа ждёт и пишет об этом. Чтобы остановиться, нажмите Ctrl+C (на Mac тоже Ctrl, не Cmd): программа закончит текущий запрос, а остальное найдёт при следующем запуске.

  6. 11

    Выйдите из аккаунта на компьютере

    В конце программа спросит, выйти ли из аккаунта на этом компьютере. Нажмите Enter, это ответ «да». Так безопаснее: файл входа открывает весь аккаунт. В следующий раз снова понадобится QR-код, а ключ вводить не придётся.

Обновить, выйти, удалить

Обновить программу

Та же команда, что при установке, но с параметром --reinstall: она скачает свежую версию и установит её поверх старой.

uv tool install --reinstall https://github.com/umbrella-at/tgsweep/archive/refs/heads/main.zip

Выйти из аккаунта позже

Если в конце вы ответили «нет», выйти можно так:

tgsweep --logout

Или на телефоне: Настройки, Устройства, сеанс tgsweep, «Завершить сеанс».

Удалить программу

Выйдите из аккаунта и удалите программу:

tgsweep --logout
uv tool uninstall tgsweep

Затем удалите папку с ключом и журналом:

Windows

Remove-Item -Recurse -Force "$env:LOCALAPPDATA\tgsweep"

macOS

rm -rf "$HOME/Library/Application Support/tgsweep"

Linux

rm -rf "$HOME/.local/share/tgsweep"

uv можно оставить: сам по себе он ничего не запускает. Если захотите удалить и его, инструкция есть в документации uv.

Чего tgsweep не делает никогда

  • не открывает личные чаты, ботов, «Избранное» и служебный чат Telegram;
  • не трогает чужие сообщения, даже если вы админ группы;
  • не трогает группы, которые вы создали, и ваши посты в каналах;
  • ничего не удаляет без вашего выбора чатов и подтверждения;
  • не отправляет ничего никуда, кроме запросов к Telegram: своего сервера и статистики у программы нет.

Зачем свой ключ

Ключ, файл входа и журнал хранятся только у вас на компьютере. У программы нет своего сервера, а у автора нет доступа к вашему аккаунту. Общий ключ на всех в открытом коде не спрятать, а опубликованный или замеченный в злоупотреблениях ключ Telegram блокирует, и программа перестала бы работать у всех сразу. Со своим ключом такого не случится.

Всё лежит в папке %LOCALAPPDATA%\tgsweep.

Всё лежит в папке ~/Library/Application Support/tgsweep.

Всё лежит в папке ~/.local/share/tgsweep.

Проверьте сами

Код открыт: github.com/umbrella-at/tgsweep. Если сами код не читаете, дайте ссылку любому ИИ-чату и спросите, что программа отправляет и что удаляет. В репозитории есть тесты, которые не дают программе лишних умений: писать сообщения, выходить из групп, удалять чужое.

Вопросы

Аккаунт не заблокируют?

Удалять свои сообщения в Telegram можно, это обычное действие. Программа удаляет с паузами и ждёт, когда Telegram просит подождать. Но она неофициальная, и гарантий за Telegram никто дать не может.

Программа видит мои личные переписки?

Telegram присылает список всех чатов, включая личные, и в нём последнее сообщение каждого чата. Программа личные чаты сразу пропускает: не читает их историю, ничего в них не удаляет и ничего о них не сохраняет. Так же с ботами, «Избранным» и служебным чатом Telegram.

А чужие сообщения? Я админ в паре групп.

Только ваши, даже если вы админ. Группы, которые вы создали сами, программа пропускает целиком, чтобы не опустошить вашу же группу.

Сообщения исчезнут у всех?

Да, как если бы вы удалили их сами в Telegram. Вернуть их нельзя, поэтому перед удалением программа просит ввести число. В журнале остаются только номера чатов и сообщений, без текстов.

Сколько это займёт?

Поиск в больших чатах занимает несколько минут. Перед удалением программа сама пишет, сколько примерно минут уйдёт. Сообщения она удаляет пачками по 100 с паузой 4 секунды, а реакции снимает по одной: тысяча сообщений уйдёт меньше чем за минуту, сто реакций займут минут семь. Если Telegram попросит подождать, выйдет дольше.

Найдёт ли программа мои старые реакции?

Реакции она ищет только в сообщениях за последние 90 дней: чтобы найти свою реакцию, ей приходится просматривать чат сообщение за сообщением, а это долго. Свои сообщения и комментарии она находит за всё время.

Что будет, если закрыть окно посреди удаления?

Удалённое останется удалённым, остальное программа найдёт при следующем запуске. Лучше нажать Ctrl+C: она закончит текущий запрос и остановится.

my.telegram.org пишет ERROR при создании приложения

Такое бывает. Обычно помогает выключить VPN и блокировщик рекламы, заполнить поля латиницей и попробовать ещё раз позже или в другом браузере.

Почему через терминал, а не обычное приложение?

Программа маленькая, и так её проще проверить: она устанавливается одной командой прямо из открытого кода, без установщика, внутри которого неизвестно что.

Программа пишет по-английски

tgsweep говорит на языке системы: если система не на русском, он переходит на английский. Включить русский: tgsweep --lang ru. Выбор запомнится, повторять не нужно.

Это программа от Telegram?

Нет. tgsweep сделал частный разработчик, с Telegram программа не связана.
